# Secuencia de demostración de 10 minutos
Grabar cuando estén terminadas las pruebas de aceptación. Mostrar la hora del teléfono y del panel para poder relacionar el paso con la captura.
| Minuto | Acción en pantalla | Evidencia que debe verse |
|---|---|---|
| 0–1 | Presentar integrantes y recorrido del fotograma | Android, API, RunPod y PostgreSQL |
| 1–2 | Iniciar sesión web y Android | Cuenta autorizada y rechazo de una cuenta fuera de lista |
| 2–4 | Capturar un vehículo de perfil con saldo de prueba | Placa, categoría, ejes, caseta, sentido, un único débito |
| 4–5 | Mostrar panel junto al teléfono | Mismo identificador del paso recibido por SSE |
| 5–6 | Probar saldo insuficiente y placa desconocida | Alertas, evidencia y saldo anterior y posterior |
| 6–7 | Probar ruedas ocultas | Revisión con evidencia, motivo y auditoría |
| 7–9 | Consultar texto y foto | Cuatro estados, sugerencia ante confusión OCR |
| 9–10 | Mostrar consola RunPod y conjunto de prueba | Modelos efectivamente cargados, métricas y limitaciones |
